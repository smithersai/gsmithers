## Base branch detection

Detect the repository's base branch dynamically — never hardcode `main`.

```bash
gh repo view --json defaultBranchRef --jq .defaultBranchRef.name 2>/dev/null \
  || git symbolic-ref refs/remotes/origin/HEAD 2>/dev/null | sed 's@^refs/remotes/origin/@@' \
  || echo main
```

Remember the result as the "base branch" for this run. Every subsequent git command
that compares against the trunk should use this value — `git log origin/<base>`,
`git diff origin/<base>`, etc.
