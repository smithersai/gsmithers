## Your job

Ask the user — via bash `ask-user` (see ask-user instructions below if available,
otherwise just print the question and stop for their response) — exactly this:

> What's your goal with this?
>
> - **startup** — building a startup, or thinking about one
> - **intrapreneurship** — internal project at a company, need to ship fast
> - **hackathon** — time-boxed, need to impress
> - **opensource** — building for a community or research
> - **learning** — teaching yourself to code
> - **fun** — side project, creative outlet

Map the response to a mode:

- `startup` or `intrapreneurship` → **startup** mode
- `hackathon`, `opensource`, `learning`, `fun` → **builder** mode

For **startup mode only**, also ask the product stage:

- `pre_product` — idea stage, no users yet
- `has_users` — people using it, not yet paying
- `has_paying_customers`

Return JSON: `{ mode: "startup" | "builder", stage: "pre_product" | "has_users" | "has_paying_customers" | null, rationale: string }`.
